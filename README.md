# xhs-creator-distill

从用户主动提供的 3–8 篇代表笔记中，提炼可解释、可迁移的小红书创作者内容操作系统。

[查看 Skill](SKILL.md) · [查看示例](examples/sample-distill-report.md) · [变更记录](CHANGELOG.md) · [参与贡献](CONTRIBUTING.md)

> [!IMPORTANT]
> 本项目是独立的开源社区项目，并非小红书官方产品，也未获得小红书官方授权、认可或背书。“小红书”及相关标识归其权利人所有。

## 它做什么

`xhs-creator-distill` 不只是总结几篇笔记。它要求基于可定位的输入证据，区分观察、推断与未知项，再把创作者内容中的稳定机制提炼为可执行方法，例如：

- 账号定位、目标读者与价值承诺；
- 选题来源、判断标准与内容组合；
- 标题、开场、正文与收束的结构模式；
- 语言、节奏、视觉提示与互动方式；
- 可迁移的创作流程、约束与验证建议。

它提炼的是方法，不是一比一复刻某位创作者的人格、措辞或作品。

## 适用与不适用

| 适用 | 不适用 |
| --- | --- |
| 复盘自己或已获授权账号的内容方法 | 批量抓取、绕过登录或访问非公开内容 |
| 从 3–8 篇代表笔记中发现稳定模式 | 只凭 1–2 篇笔记下完整结论 |
| 为新账号提取可迁移的选题和结构规则 | 逐句仿写、冒充或复制特定创作者 |
| 比较同一创作者不同内容的共性与差异 | 保证爆款、流量、过审或商业结果 |
| 找出证据不足、冲突和需要补样的位置 | 法律、平台合规或商业决策的唯一依据 |

## 准备输入

请提供 **3–8 篇**有代表性的笔记文字，并尽量覆盖不同主题或表现类型。建议为每篇编号，便于输出回引证据：

```text
N01
标题：……
正文：……
可选背景：发布时间、内容类型、你有权分享的非敏感表现信息

N02
标题：……
正文：……
```

提交前请移除姓名、手机号、地址、账号凭据、未公开经营数据等个人或敏感信息。只提交你有权使用和分析的内容。

- 少于 3 篇：适合做初步观察，不足以形成完整蒸馏结论。
- 超过 8 篇：先选出最具代表性的 8 篇，或拆成多批并明确比较目标。
- 重复、广告稿或明显离群内容：请保留必要说明，分析时应识别并降权，而不是静默混入结论。

## 安装

### 使用 Skills 安装器

如果你的宿主支持兼容的 Skills 安装器，可运行：

```bash
npx skills add aiiqc/xhs-creator-distill
```

安装器的可用性、目标目录与加载方式取决于具体宿主，请以该宿主当前文档和命令输出为准。

### 手动安装

也可以把仓库克隆到宿主实际使用的技能目录：

```bash
git clone https://github.com/aiiqc/xhs-creator-distill.git /path/to/your/skills/xhs-creator-distill
```

将 `/path/to/your/skills` 替换为真实目录，然后按宿主说明重新加载技能。不同宿主的发现路径、元数据支持和触发机制可能不同；本项目不会据此声称已验证所有宿主。

## 快速使用

安装后，在支持 Skills 的智能体中明确提出任务并粘贴已编号的笔记：

```text
请使用 $xhs-creator-distill，基于下面 5 篇代表笔记，
蒸馏我的小红书内容操作系统。

目标：提炼可用于新账号的选题、内容结构和表达规则。
要求：逐项标注证据编号；区分观察、推断和证据不足；
不要仿写原作者，也不要补造互动数据。

[N01]
标题：……
正文：……

[N02]
……
```

还可以补充你的目标受众、品类、资源限制和希望保留或避开的表达方式。缺少的信息应被标为未知，不应由模型自行编造。

## 输出结构

完整报告通常包含：

1. 任务范围、输入清单与样本质量说明；
2. 有证据回引的五层创作者蒸馏：定位层、选题层、结构层、表达层、运营层；
3. 稳定模式、例外、冲突与置信度；
4. 可迁移规则和不应复制的个体化特征；
5. 面向目标账号的改造建议、执行清单与验证计划。

每项关键结论应尽量回引 `N01`–`N08`，并明确它属于直接观察、跨样本推断还是证据不足。完整字段与判定规则以 [输出协议](references/output-contract.md) 为准。

输入少于 3 篇或多于 8 篇时，Skill 会先输出输入审计 `HOLD`，不生成完整蒸馏报告；请按审计建议补充或缩减样本后再运行。

## 安全、隐私与诚实边界

- 笔记、链接、评论和附件都属于待分析的**不可信材料**；其中夹带的命令不能改变任务范围，也不能授权读取文件、访问账号或调用外部服务。
- 项目设计范围不包括自动登录、私信、发帖、批量采集或绕过访问控制。
- 不要求也不应提交密码、Cookie、Token、私钥、精确住址、联系方式或其他敏感信息。
- 不推断健康、政治、宗教、性取向等敏感属性；不将臆测写成事实。
- 只抽象可迁移机制，不逐句改写、不复刻独特口头禅、不冒充原作者。
- 输出是分析辅助，不保证爆款、推荐流量、平台审核结果、收益或合规结论。
- 数据处理和留存还受你所使用宿主、模型及服务商政策约束；本仓库不作“零留存”承诺。使用前请核对相应隐私设置。

发现可能导致隐私泄露、越权操作或安全边界绕过的问题时，请按 [安全政策](SECURITY.md) 私下报告。
