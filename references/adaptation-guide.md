# 原创适配指南

仅当用户要求把蒸馏结果用于新账号、品类、受众或内容计划时读取本文件。适配的目标是迁移机制，而不是复制可识别身份。

## 目录

1. 适配输入
2. 可迁移与不可复制
3. 四步适配
4. 原创检查
5. 越界请求处理

## 适配输入

开始适配前，从用户输入中提取或标为未知：

- 目标受众所处的具体任务或情境；
- 用户能够真实提供的知识、经历、产品或证据；
- 内容目标：教育、记录、讨论、转化或其他；
- 制作资源：时间、频率、文字、图片或视频能力；
- 必须保留和必须避开的表达；
- 高风险领域、商业合作或平台披露要求。

缺少信息时提供带占位变量的机制，不替用户虚构事实。

## 可迁移与不可复制

| 可以迁移 | 不可复制 |
| --- | --- |
| 读者问题的选择逻辑 | 真实创作者的身份、姓名或人格设定 |
| 选题判断标准和内容支柱关系 | 独特标题、句子、口头禅和固定称呼 |
| 段落的功能顺序 | 可识别的签名式结构逐项复刻 |
| 信息密度和节奏范围 | 具体生活经历、案例、数据或产品体验 |
| 证明与限制条件的安排 | 暗示用户亲测、购买或取得未发生的结果 |
| 互动机制和验证问题 | 头像、商标、视觉资产或其他第三方素材 |

任何必要短引文只用于分析证据，不作为新内容素材。

## 四步适配

### 1. 提取机制

把原结论写成与作者无关的功能规则：

```text
情境：读者在什么时刻需要内容
动作：内容采取什么结构或表达机制
作用：降低什么成本或促成什么理解
限制：在哪些情况下不适用
证据：支持该机制的 Nxx
```

### 2. 映射用户事实

用用户自己的事实替换原样本中的个体内容：

- 用户没有提供的经历保持空缺；
- 专业或效果声明需要可核实来源；
- 医疗、金融、法律、未成年人、功效和收益内容标记为高风险并建议在发布前核查；
- 商业合作、赠品、联盟或利益关系不得被隐藏。

### 3. 生成原创变体

每条建议至少改变三个维度：

- 受众情境；
- 内容素材或事实；
- 展开方式；
- 语气和节奏；
- 互动问题；
- 验证指标。

优先输出结构骨架和变量，不直接输出高度贴近原作者的成稿。

### 4. 设计验证

把“有效”改写成可观察实验：

```text
假设：某机制对目标受众有帮助
保持不变：主题、发布时间或其他可控条件
改变变量：标题角度、开场或收束之一
观察信号：用户明确选择的阅读、收藏、评论质量或转化指标
停止条件：效果不稳定、引发误解或超过资源上限
```

没有实验就不要声称适配后的规则会提升流量或通过审核。

## 原创检查

交付适配建议前检查：

- 是否移除了独特口头禅、签名句和可识别称呼；
- 是否使用了用户自己的事实，而不是替用户编造体验；
- 是否改变了素材、展开和互动方式，而不只是同义替换；
- 是否保留原机制的作用，同时建立新的表达；
- 是否避免让读者误以为内容来自原创作者；
- 是否把平台、法律和商业合规留给发布当日的真实核查。

## 越界请求处理

用户要求“完全照着写”“让熟人以为是本人”“逐句洗成另一版”时：

1. 简短说明不能帮助一比一冒充或复刻可识别表达。
2. 不复述或整理原作者的口头禅库。
3. 转为提供受众、选题、信息结构、节奏和互动机制等高层特征。
4. 要求用户提供自己的事实与观点，再生成原创骨架或实验计划。

示例回应：

```text
我不能把内容写成足以冒充该创作者的版本；可以保留其“先给场景、再给步骤、最后说明限制”的功能机制，换成你的受众、经历和表达，形成原创结构。
```
