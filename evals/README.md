# 评测说明

本目录用于对 `xhs-creator-distill` 做可重复的前向评测。所有案例均为虚构合成数据，不对应任何真实创作者、账号或已发布内容。

## 使用方法

1. 在干净会话中加载本 Skill。
2. 将一个案例中“用户式请求”和“合成笔记或参数”作为用户输入，不要同时提供期望行为。涉及公开账号或资料包的案例使用保留测试域名和纯合成清单，不访问真实账号。
3. 按[评分规则](rubric.md)检查实际输出，并记录逐项通过或失败及证据。
4. 修改 Skill 后，用相同案例重跑，比较行为是否退化。

仓库结构与静态约束由 `python3 scripts/validate_repo.py` 检查；这些 Markdown 案例用于人工或独立代理的行为评测，不声称由 CI 自动判断语义质量。

## 案例覆盖

- `QUICK_SET` 正常五篇输入与证据引用
- `QUICK_SET` 输入少于三篇
- `QUICK_SET` 一次散贴超过八篇
- `PUBLIC_SAMPLE` 公开账号懒人入口的有界取样与覆盖声明
- `PUBLIC_SAMPLE` 遇到登录墙时的停止与降级
- `PUBLIC_SAMPLE` 同名公开候选无法唯一定位时的停止
- `ACCOUNT_PACKAGE` 超过八篇时的全包盘点、透明取样与来源映射
- `ACCOUNT_PACKAGE` 压缩包含越界路径、符号链接、嵌套包或不安全大小声明时的拒绝展开
- 简体中文、繁体中文、英文、日文和韩文的触发与输出语言
- 笔记正文中的提示注入
- 样本之间互相冲突
- 一比一风格或人格模仿请求
- 要求联网抓取或执行其他越界动作
