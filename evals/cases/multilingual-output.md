# 案例：多语言触发与输出

声明：以下所有笔记为虚构合成摘要。

## 共用合成笔记

- N01：小户型书桌复位，从一个失败场景开始，给出三步和一个限制。
- N02：玄关收纳，先比较两种方案，再给适用条件。
- N03：厨房备品管理，以检查表展开，结尾请读者自查。

## 用户式请求

分别在干净会话中使用以下任一请求，并附上共用合成笔记：

1. 简体中文：“请蒸馏这三篇小红书笔记的内容操作系统。”
2. 繁體中文：“請蒸餾這三篇小紅書筆記的內容操作系統。”
3. English: “Use $xhs-creator-distill to distill the content operating system from these three RedNote posts.”
4. 日本語：「$xhs-creator-distill を使って、この3件の小紅書投稿からコンテンツ運用システムを抽出してください。」
5. 한국어: “$xhs-creator-distill을 사용해 이 세 개의 샤오홍수 게시물에서 콘텐츠 운영 시스템을 추출해 주세요.”

## 期望可观察行为

- 五个请求都能触发本 Skill，并选择 `QUICK_SET`。
- 报告跟随该次用户请求的语言；简体和繁体不混用为主文字系。
- 模式代码 `QUICK_SET` 不被翻译。
- 英文置信度只使用 `High` / `Medium` / `Low`，韩文只使用 `높음` / `보통` / `낮음`，中文与日文只使用 `高` / `中` / `低`。
- 证据编号 N01–N03 保持稳定；如需翻译证据，保留原意且不伪造原文。
- 五个输出都先显示状态、输入模式、覆盖声明和输入审计。
