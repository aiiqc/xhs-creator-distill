# 真实世界自测

本目录记录维护者在公开或经授权材料上执行的有限自测。它与 [`evals/cases`](../../evals/cases/) 的合成行为评测分开，且不会由 CI 联网重跑。

这些记录只能证明所列输入、日期和证据层级下的结果：

- `MAINTAINER_SELF_TEST`：由维护者执行，不是独立外部用户采用。
- `CROSS_PLATFORM_PROTOCOL_ONLY`：只验证蒸馏协议，不是小红书平台兼容性证明。
- `ANONYMOUS_ACCESS_SMOKE`：只验证未认证入口的有限响应，不证明正文完整或语义质量。
- 小红书入口的预期 `HOLD` 可证明安全降级正确，但不是正向小红书 E2E。

## 数据与留存边界

- 仓库不保存第三方全文、网页 HTML、截图、图片、Cookie、会话、请求头或浏览器配置。
- 结果只保留必要的规范 URL、日期、数量、内容指纹、证据 ID 和转换后的分析。
- 小红书失败案例不保存原短链、路径、查询参数、跳转目标或可关联 URL 哈希。
- 外部页面会变化；本目录是历史执行记录，不承诺未来重复访问会得到相同结果。
